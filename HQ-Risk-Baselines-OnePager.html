HQ-Risk — S1 / S2 baselines, first real numbers

2026-09-07 · 375 runs · 5 seeds each · every row reproducible and stamped with the code commit · S3 (quantum) not started, awaiting the circuit

Every attack hurts more as it gets stronger, in every sweep. The ground truth the score must track is now measured, with error bars. Evasion is the most damaging (ε = 0.1 already costs 7–11 pp). Targeted poisoning hides behind accuracy: 81 % accurate while missing half the malignant cases. FedAvg absorbs up to 3 malicious clients in 10, then collapses at 5.

Process

1 · Split80/20 stratified, features standardised on train only
2 · CleanLogistic regression trained and scored — the baseline
3 · PoisonFlip 5–40 % of training labels, retrain, same test set
4 · EvadeFGSM on the test set, ε = 0.1–1.0 in sd units
5 · Federate10 clients, FedAvg, 30 rounds, IID + non-IID; 1–5 clients malicious
6 · RepeatSeeds 0–4 for every point; mean ± sd; append-only CSV

Each run trains a clean and an attacked model on the same split, so clean-vs-attacked is a paired comparison. Test set is fingerprinted and asserted untouched. Same seed twice → identical row. FGSM gradients verified against finite differences.
